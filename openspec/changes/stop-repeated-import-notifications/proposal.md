# 반복 가져오기 알림 억제

## Why

Auto-Tong 0.3.0은 원본이 삭제되어도 손상된 로컬 설치 기록의 복구 오류를 스캔마다 알린다. 게임 실행으로 설치가 보류되면 실패 횟수를 기록하지 않아 가져오기 준비가 반복되며, 실패 이력 저장 자체가 실패하면 기존 재시도 의도가 남는다. 초기 journal 쓰기 실패가 빈 복구 기록을 남기는 경로도 확인했다.

## What Changes

- 같은 미해결 오류의 데스크톱 알림과 보류 진행 이벤트를 중복 생성하지 않는다.
- 무거운 가져오기 작업 전에 런처 상태를 확인하고, 설치 확정 직전 검사를 유지한다.
- 준비 단계 실패도 재시도 한도에 포함한다. 실패/취소 저장 장애에서는 실행 중 보호 상태로 같은 콘텐츠의 자동 재실행을 막는다.
- 파일 내용이 같고 수정 시각만 바뀐 경우 실패 재시도 횟수를 초기화하지 않는다.
- 최초 설치 journal을 완전히 쓴 뒤 공개하여 초기 실패 때 손상된 복구 기록이 남지 않도록 한다.

## Impact

watcher, Prism 상태 판정, Tracker, 설치 journal 초기화와 관련 테스트만 변경한다. 이력 스키마는 유지하며 후속 배포 요청에 따라 제품 버전은 0.3.1로 변경한다. 기존 사용자 journal/백업을 자동 삭제하거나 실제 사례의 최초 오류 원인을 추정하지 않는다. 후속 배포 요청으로 PR·CI 검증 후 릴리스 발행까지 진행한다. 사용자 PC에 직접 설치하는 작업은 포함하지 않는다.
