# Spec Delta

## Purpose

사용자가 선택한 PrismLauncher에 올바른 인스턴스와 실행 환경을 연결하고, 게임 실행 여부가 불확실한 상황에서도 프로세스와 사용자 데이터를 보존하면서 변경을 반영한다.

## ADDED Requirements

### Requirement: 선택한 런처의 데이터 위치

시스템은 선택한 Prism 실행 파일과 검증된 데이터 위치를 하나의 대상으로 다뤄야 한다(SHALL). 기본 설치와 portable 설치가 함께 존재할 때 기본 폴더의 존재만으로 대상을 결정하지 않아야 한다(MUST).

#### Scenario: 기본 설치와 portable 설치 공존

- **WHEN** 사용자가 portable 실행 파일을 선택했고 기본 설치 데이터도 존재한다
- **THEN** 확인된 portable 데이터 위치로 가져오며 위치를 결정할 수 없으면 명시적 선택을 요청한다

### Requirement: 정확한 로더와 Java 호환성

시스템은 Prism이 지원하는 로더 식별자를 생성하고 해당 Minecraft 버전의 검증된 Java 요구사항에 맞는 실행 환경을 설정해야 한다(SHALL). 버전을 해석할 수 없을 때 임의로 Java 21을 지정하지 않아야 한다(MUST).

#### Scenario: NeoForge 팩

- **WHEN** MRPACK에 NeoForge 의존성이 있다
- **THEN** 생성된 로더 component UID는 `net.neoforged`이며 바닐라 ZIP 변환과 같은 매핑을 사용한다

#### Scenario: Minecraft 26.1

- **WHEN** Minecraft 26.1의 런타임 요구사항을 해석한다
- **THEN** 검증된 버전 메타데이터에 따라 Java 25를 선택하며 Java 21 경로를 강제로 설정하지 않는다

#### Scenario: 미확인 버전 또는 메타데이터 장애

- **WHEN** 사용 가능한 검증된 요구사항이 없는 버전을 가져온다
- **THEN** 실행 환경을 확인할 수 없다는 상태를 표시하고 임의의 런타임으로 설치 완료 처리하지 않는다

### Requirement: 런타임 설치의 완전성

시스템은 Java 실행 파일의 존재뿐 아니라 실행 가능 여부, 버전, 아키텍처와 다운로드 무결성을 검증해야 한다(SHALL). 불완전한 런타임을 정상 캐시로 재사용하지 않아야 한다(MUST).

#### Scenario: 불완전한 Java 디렉터리

- **WHEN** `javaw.exe`는 있지만 올바르게 실행되지 않거나 필수 런타임 파일이 없다
- **THEN** 검증된 런타임을 다시 준비하거나 가져오기를 실패 처리한다

### Requirement: 확인된 상태에서만 설치 반영과 재실행

시스템은 프로세스 조회 실패와 미실행 상태를 구분해야 한다(SHALL). 게임 실행 중이거나 상태가 불확실하면 기존 인스턴스 확정과 런처 자동 종료를 보류해야 한다(MUST). 설치 반영 전에 실행 중이었던 런처만 정상 종료를 확인한 뒤 다시 실행해야 한다(SHALL).

#### Scenario: 프로세스 조회 실패

- **WHEN** 프로세스 권한 또는 조회 오류로 Java 실행 여부를 알 수 없다
- **THEN** 런처를 강제 종료하지 않고 보류 이유와 재시도 상태를 표시한다

#### Scenario: 실행 전 상태 보존

- **WHEN** 설치 반영 전에 선택한 런처가 꺼져 있다
- **THEN** 설치 후에도 런처를 자동 실행하지 않는다

#### Scenario: 종료 또는 재실행 실패

- **WHEN** 런처의 정상 종료가 완료되지 않거나 재실행에 실패한다
- **THEN** 실패 단계와 설치 상태를 구분해 표시하고 새로고침 성공으로 보고하지 않는다
