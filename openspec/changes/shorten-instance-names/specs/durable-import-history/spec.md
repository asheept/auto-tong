## ADDED Requirements

### Requirement: 짧은 새 인스턴스 이름과 안정적인 매핑

시스템은 새 인스턴스 이름에 원본 이름의 `@`를 보존하고 소문자 16진수 4자리 접미사를 붙여야 한다(SHALL). 이력 식별에는 기존 전체 원본 해시를 유지해야 한다(MUST). 다른 매핑 또는 기존 설치 경로와 이름이 겹치면 비어 있는 다른 4자리 접미사를 선택하고, 이미 저장한 매핑은 재시작 후에도 그대로 재사용해야 한다(SHALL).

#### Scenario: @를 포함한 새 팩

- **WHEN** `2610_뜰릿밸리4화_@everyone_v01.zip`을 처음 가져온다
- **THEN** 인스턴스 이름은 `@`를 유지하고 접미사는 정확히 4자리 소문자 16진수가 된다

#### Scenario: 짧은 이름 충돌

- **WHEN** 새 후보 이름이 다른 원본의 저장된 매핑 또는 실제 설치 위치의 하위 이름과 대소문자만 다르거나 동일하다
- **THEN** 기존 대상을 변경하지 않고 다른 비어 있는 4자리 접미사를 선택한다
- **AND** 사용 가능한 이름이 없거나 설치 위치를 확인할 수 없으면 새 매핑을 확정하지 않는다

#### Scenario: 이전 매핑 유지

- **WHEN** 같은 원본에 기존 12자리 또는 구버전 이름의 매핑이 저장되어 있다
- **THEN** 새 이름 규칙으로 다시 할당하거나 설치 폴더를 변경하지 않고 저장된 매핑을 재사용한다
