# 구현 및 완료 기준

1. 작업 브랜치에서 원본 식별자 계산을 유지하고 표시 이름의 `@` 허용 및 4자리 접미사를 적용한다.
2. 새 매핑 할당 시 저장된 다른 매핑과 설치 폴더의 직접 하위 이름을 대소문자 구분 없이 확인한다. 후보부터 16비트 공간을 순회하며 비어 있는 이름을 선택하고 기존 원자적 저장 경로로 확정한다.
3. 강제로 만든 접미사 충돌, 실제 경로 점유, 재시작 후 매핑 재사용, 기존 12자리 매핑 보존을 회귀 검사한다. 해시 충돌이 없을 것이라는 확률적 단언은 사용하지 않는다.
4. 코드 리뷰, Rust 형식·clippy·전체 테스트·Windows 빌드와 기존 CI의 JavaScript 검사를 실행하고 결과를 기록한다.

새 이름에만 적용한다. 기존 매핑을 자동 변경하면 다른 인스턴스 설치나 재가져오기로 이어질 수 있으므로 이력 스키마와 전체 원본 ID를 그대로 사용한다.
