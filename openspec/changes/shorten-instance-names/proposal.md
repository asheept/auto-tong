# 인스턴스 이름의 짧은 식별값과 @ 보존

## Why

새 팩을 가져오면 원본 이름의 `@`가 `-`로 바뀌고 12자리 해시가 인스턴스 이름과 런처 표시명에 붙는다. 사용자는 `@` 보존과 4자리 식별값을 요청했다.

## What Changes

- 새 인스턴스 이름에서 `@`를 보존하고 접미사는 소문자 16진수 4자리로 만든다.
- 원본 식별과 이력에 사용하는 전체 SHA-256은 유지한다.
- 저장된 매핑 또는 실제 설치 경로와 이름이 겹치면 사용 가능한 다음 4자리 값을 선택한다. 가능한 값이 없거나 점유 상태를 확인할 수 없으면 설치 전에 오류로 중단한다.
- 이미 저장된 인스턴스 매핑과 기존 이력 이전 규칙은 보존한다. 설치된 인스턴스를 자동으로 이름 변경하지 않는다.

## Impact

`src-tauri/src/source.rs`, `src-tauri/src/tracker.rs` 및 해당 회귀 검사. 제품 버전, 설치된 앱, 원격 브랜치와 릴리스는 이 변경에서 갱신하지 않는다.
